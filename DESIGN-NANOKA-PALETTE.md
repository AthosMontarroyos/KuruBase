# Nanoka palette refinement

The Signal Atlas layout remains unchanged. This palette uses the supplied `nanoka-kurobe-banner-birthday-plush.jpg` as visual authority rather than using the character image as interface decoration.

The dominant sampled values are near-white, graphite, cool gray, and muted plum. The UI translates those into a lavender-graphite system: pale lilac surfaces, charcoal text, dusty mauve action states, and an aubergine-charcoal dark mode. Blue is removed entirely.

Color roles remain semantic: mauve marks interaction and selection, ready is a quiet neutral state, attention is dusty rose, and data uses a slightly deeper plum. Status labels and icons remain explicit so color is never the only signal.
